# 手機監測 PhoneMonitor

深色儀表板,七個分頁(上方可左右滑動):
- **即時**:電量圓環、剩餘可用時間、電池健康/剩餘 mAh/溫度/電流功率/循環、記憶體與儲存比例、網路、電池/裝置/網路詳細規格
- **趨勢**:1小時~7天的耗電速率、充放電時間、亮屏時間、用量長條圖、各項折線圖
- **電池**:充放電週期分析、亮屏/待機耗電、充電速度與溫度、等效循環、滿電停留、時段耗電、容量趨勢、充電建議
- **應用**:螢幕時間、解鎖次數、各 App 使用時間、每日上限提醒、一鍵開啟 App 資訊/解除安裝
- **網路**:行動網路/Wi-Fi 用量、每日趨勢、各 App 前景/背景流量、月流量上限
- **隱私**:麥克風/相機使用偵測、特殊權限(無障礙/通知存取/裝置管理員/懸浮視窗)盤點、敏感權限稽核、背景常駐偵測
- **設定**:背景監測、取樣間隔、匯出 CSV、診斷

「應用 / 網路 / 隱私」需開啟「使用情況存取權」(首次進入該頁會引導)。
本 App 沒有網路權限,資料只存在手機。

## 使用
1. 建立 **Private** repo,上傳全部檔案(含 `.github`)到 main。
2. Actions 跑完後到 Releases 下載 APK 安裝;之後 push 即自動出新版,直接安裝覆蓋更新。
3. 簽名金鑰 `keystore/release.jks` 由第一次 Actions 自動產生並保存,請勿刪除、repo 保持私有。
