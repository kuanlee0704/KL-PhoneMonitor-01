# 手機監測 PhoneMonitor

深色儀表板,七個分頁(上方可左右滑動):
- **即時**:電量圓環、剩餘可用時間、電池健康/剩餘 mAh/溫度/電流功率/循環、記憶體與儲存比例、網路、電池/裝置/網路詳細規格
- **趨勢**:1小時~7天的耗電速率、充放電時間、亮屏時間、用量長條圖、各項折線圖
- **電池**:充放電週期分析、亮屏/待機耗電、充電速度與溫度、等效循環、滿電停留、時段耗電、容量趨勢、充電建議
- **應用與專注**(三個子頁):
  - 使用統計:螢幕時間、解鎖、各 App 排行,點選可 退出 / 封鎖 / 專注清單 / 每日上限 / 網路封鎖
  - 封鎖專注:永久封鎖、專注模式(25分/1小時/2小時)、排程專注、每日上限可選「通知」或「直接封鎖」、嚴格模式
  - 短影音防護:只擋 Instagram Reels / YouTube Shorts / Facebook Reels,可完全封鎖或每日額度
- **網路**:行動/Wi-Fi 總覽、月流量上限、每日趨勢、前景/背景流量排行、App 網路封鎖(本機 VPN)
- **隱私**(五個子頁):總覽(狀態與待處理)/ 偵測(麥克風與相機時間軸)/ 權限(敏感權限稽核,可依類型篩選)/ 特殊(無障礙、裝置管理員、通知存取等)/ 背景(長時間常駐);可標記「信任」的 App
- **設定**:背景監測、取樣間隔、匯出 CSV、診斷

「應用 / 網路 / 隱私」需開啟「使用情況存取權」(首次進入該頁會引導)。
本 App 沒有網路權限,資料只存在手機。

## 使用
1. 建立 **Private** repo,上傳全部檔案(含 `.github`)到 main。
2. Actions 跑完後到 Releases 下載 APK 安裝;之後 push 即自動出新版,直接安裝覆蓋更新。
3. 簽名金鑰 `keystore/release.jks` 由第一次 Actions 自動產生並保存,請勿刪除、repo 保持私有。

## 封鎖功能需要的權限
- 無障礙服務「手機監測 · 專注防護」:封鎖、專注、短影音防護(只在本機判斷)
- Android 13+ 側載 App 若開關灰色:App 資訊 → ⋮ → 允許受限制的設定
- 網路封鎖:啟用時系統會要求 VPN 授權

## 密碼保護
- 設定 → 密碼保護:4–8 位數字 PIN,以 PBKDF2-SHA256 加鹽雜湊儲存;連續輸錯 5 次起暫時鎖定(逐次加倍,最長 10 分鐘)。
- 需要密碼的操作:放寬/解除封鎖、專注、每日上限、短影音防護、網路封鎖,停止監測、清除資料、修改密碼,以及封鎖畫面上的「多給 5 分鐘」。新增限制不需密碼。
- 可選「開啟 App 時要求密碼」。驗證後 5 分鐘內免再輸入。
- 限制:無法阻止到系統設定關閉無障礙服務、清除資料或解除安裝;忘記密碼只能清除 App 資料(同時清空紀錄與規則)。

## 時間自訂
每日上限、專注時間、短影音額度、封鎖畫面延長時間、取樣間隔、每月流量上限,皆可選常用值或「自訂…」(小時+分鐘 / 數字)。

## 短影音防護的效能設計
偵測改為「定點查詢」(單次 IPC,不遍歷整棵畫面樹),需連續 2 次偵測到才動作,動作後 2.5 秒內不再偵測,
15 秒內觸發 3 次會自動暫停 1 分鐘(斷路器),避免誤判造成畫面一直被刷新。
