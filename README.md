# 手機監測 PhoneMonitor

深色儀表板 App,三個分頁:
- **即時**:電量圓環、剩餘可用時間、電池健康度/剩餘 mAh/溫度/電流功率/充電循環、記憶體/儲存比例、網路、熱狀態
- **趨勢**:1小時/6小時/24小時/7天;耗電速率、充放電時間、亮屏時間、用量長條圖、電量/溫度/電流/電壓/記憶體折線圖(可觸控查看)
- **設定**:背景監測開關、取樣間隔、匯出 CSV、清除資料

## 使用
1. 建立 **Private** repo,上傳全部檔案(含 `.github` 隱藏資料夾)到 main。
2. Actions 跑完後,到 Releases 下載 APK 安裝。
3. 之後 push 新程式碼 → 自動出新版 → 直接安裝即覆蓋更新(資料保留)。

## 覆蓋更新
- 第一次 Actions 會產生簽名金鑰 `keystore/release.jks` 並存回 repo,之後固定使用。請勿刪除,repo 保持私有。
- versionCode = Actions 執行編號,自動遞增。
- `applicationId` 發布後請勿修改。
